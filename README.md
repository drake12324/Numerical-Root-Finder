# Numerical Root Finder

## Project Description
Numerical Root Finder is a Python application designed to find the roots of mathematical equations using numerical methods.

## Project Purpose
The purpose of this project is to help users find estimated answers to mathematical equations through a simple application.

## Features
- Accepts mathematical equations from users.
- Uses numerical methods to find roots.
- Displays the calculated results.
- Provides a simple and easy-to-use interface.
