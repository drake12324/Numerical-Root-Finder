
# Numerical Root Finder

## Project Description
Numerical Root Finder is a Python program designed to find the roots of polynomial equations using numerical methods.

## Project Objectives
- Find approximate roots of polynomial equations.
- Apply the Bisection Method and Newton-Raphson Method.
- Support linear, quadratic, and cubic equations.
- Display calculation results and iterations.

## Numerical Methods
1. Bisection Method
2. Newton-Raphson Method

## Supported Equations
- Linear equations
- Quadratic equations
- Cubic equations

## Technologies Used
- Python

## How to Run the Program

1. Install Python 3.
2. Open Terminal.
3. Navigate to the project folder.
4. Run the following command:

   python3 main.py

## Current Development Status
The main menu and input collection are currently implemented. Integration of the numerical methods is still in progress.
